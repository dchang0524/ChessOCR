# Third-party piece sets

The PNGs in the directories below are lossless raster conversions of SVG piece sets from
[lichess-org/lila](https://github.com/lichess-org/lila), pinned at commit
`cf0c9f3e45415135f3e2261b4ef8c9b2cf5631c1`. The conversion changes the file format and size
but does not intentionally alter the artwork.
